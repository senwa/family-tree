# 📜 家谱 · 家族世系图

一个基于 **Vue 3 + Vite** 的中国风家谱可视化应用。支持以交互式树形展示家族世系，提供搜索、统计、增删改、导入导出与打印等功能，数据自动保存在浏览器本地。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🌳 世系树展示 | 递归渲染家族树，含配偶卡片、世代标记、性别图标、连接线系统 |
| 🔍 搜索 / 筛选 | 按姓名搜索 + 按世代 / 性别 / 状态（在世·已故·未婚·已婚）筛选，命中节点高亮 |
| 🖱️ 缩放 / 拖拽 | 鼠标滚轮缩放、拖拽平移，支持触摸双指缩放 |
| 👤 详情查看 | 点击节点弹出详情（生卒年、享年、配偶、简介、子女跳转） |
| ✏️ 增删改成员 | 在详情中编辑成员、添加子女、删除（含后代），根节点受保护 |
| 💾 本地持久化 | 数据自动保存到 `localStorage`，刷新不丢失 |
| 📊 家族统计 | 总人数、世代数、男女比例、在世/已故、婚配数、平均年龄、世代分布图 |
| 📂 导入 / 导出 | 支持 JSON 文件拖拽导入（含格式校验）与导出 |
| 🖼️ 导出图片 | 一键将整棵树导出为高清 PNG |
| 🖨️ 打印 | 打印或另存为 PDF，仅输出家谱树 |

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

开发服务器默认运行在 `http://localhost:5173`。

## 📦 技术栈

- **Vue 3**（`<script setup>` 组合式 API）
- **Vite** 构建工具
- **html-to-image**（PNG 导出）
- 纯 CSS 中国风视觉（暗红 + 描金），无 UI 框架依赖

## 📋 数据格式

家谱数据为嵌套 JSON，每个成员结构如下：

```json
{
  "id": "1",
  "name": "张德厚",
  "gender": "male",
  "birthYear": "1920",
  "deathYear": "1998",
  "generation": 1,
  "avatar": "",
  "bio": "生平简介……",
  "spouses": [
    {
      "name": "李秀兰",
      "gender": "female",
      "birthYear": "1922",
      "deathYear": "2005",
      "bio": "配偶简介……"
    }
  ],
  "children": [ /* 子节点数组，结构相同 */ ]
}
```

**必填字段**：`id`、`name`。`gender` 取值 `male` / `female`，`generation` 表示世代（始祖为 1）。

**头像**：`avatar` 为可选的图片 URL / data 链接；留空则显示姓名末字文字头像。头像随性别着色（男蓝/女粉），已故者自动变灰。

**配偶**：使用 `spouses` 数组，支持多位配偶（按顺序显示为 元配 / 继配 / 三配…）。也兼容旧的单数 `spouse` 对象，二者不可同时存在。

**子女生父/生母**：子女节点可加可选字段 `birthSpouseIndex`（数字），指向其父/母的 `spouses` 数组下标，表示该子女由哪位配偶所出；详情中会显示「母：X / 父：X」。

> 导入时仅需保证根节点与各子节点结构一致，`generation` 建议填写以便统计；新增成员的世代会根据其位置自动推算。

## 💡 使用提示

- **滚轮**缩放、**拖拽**平移画布，**点击**节点查看详情。
- 在详情弹窗中可 **编辑** 当前成员、**添加子女**、**删除**（删除会一并移除其后代，根节点不可删）。
- 数据变更会自动保存到浏览器本地；点击「🏠 示例」可恢复内置示例数据。
- 导出图片 / 打印前会自动重置视图，确保捕获到完整的家族树。
